      Comment lire la frise ?
      • Chaque œuvre est un point relié aux autres par le fil noir, dans l’ordre choisi (sortie ou histoire).
      • Les œuvres d’un autre univers (Terre-828, Terre-10005) sont en fuchsia, avec le nom de leur univers ; le fil s’en écarte en tirets.
      • À l’arrivée, la vue d’ensemble montre toute la frise : molette vers le haut, + ou un clic sur la frise pour zoomer ; molette vers le bas ou − pour revenir.
      • L’aiguille rouge désigne l’œuvre exposée : faites glisser la frise (ou Maj + molette), ou passez d’une œuvre à l’autre avec ‹ › ou les flèches du clavier.
      • Choisissez une œuvre pour ouvrir ses Archives ; Échap pour revenir.
